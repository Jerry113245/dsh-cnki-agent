# 精读检查单（核心期刊编辑视角）

## A 元信息
- 期刊层级 / 栏目 / 年卷期 / 作者与机构 / 基金
- 判断：问题描述型、理论建构型还是实证检验型

## B 目录与小标题
- 一级标题的关系：并列 / 递进 / 对照
- 是否存在"对象—框架—实证—讨论"四段式
- 篇幅是否失衡（讨论过短、文献堆砌过长）

## C 引言解剖（逐句标注）
1. 现实背景句（是否有可核验事实或数据）
2. 已有研究句（是否点名具体学者与观点）
3. 转折缺口句（是否用"然而/但/尚缺乏"显式点出）
4. 研究问题句（单一、可回答、有边界）
5. 贡献句（理论贡献与实践贡献分别写）
6. 结构预告句

常见缺陷：缺口没说清；研究问题多个且互相不咬合；贡献只是"具有重要意义"。

## D 正文覆盖
- 概念界定是否区分相近概念
- 理论基础是否被真正使用
- 研究设计：资料来源、样本、变量/编码、分析方法、效度
- 发现：是否回应研究问题，有没有反例
- 讨论：是否回扣理论，是否交代边界与局限

## E 学术语体与 AIGC 特征
- 名词化、被动使用是否恰当
- 因果措辞强度 vs 证据强度（相关/影响/导致/决定）
- 限定词是否到位（显著、部分、在…条件下）
- AIGC 味：模板连接词堆叠、每段同结构、无具体主语的空转句

## F 可仿写点
- 3 条句型骨架（保留语法槽位，不给原文）
- 1 条结构模板（把该文骨架映射到用户主题）
