# 去 AI 味与语体配平（de-AIGC playbook）

> 这份文件解决一个问题：**让论文读起来像人写的，但仍然是论文。**
>
> 两个方向都会毁稿：
> - 不改 → 模板句式、整齐并列、空洞拔高，检测器与人都会觉得"这是机器稿"；
> - 改过头 → 满篇口语、网络词、碎句，机审可能过了，人审（导师、外审）直接打回。
>
> **语体优先于数值。** 宁可保留一点生硬，也不靠口语化去凑"降低率"。

---

## 0. 检测器到底在看什么

三个常识先摆清楚，能省掉一半无效努力：

1. **它测的是"写作模式的规律性"，不是"内容真假"。** 句子长度过于均匀、连接词出现频率过于稳定、段落结构高度对称、用词永远走概率最高那条路 —— 这些才是特征。人写的东西是忽长忽短、有犹豫、有跳步的。
2. **同义词替换基本无效。** 只换词不改句式，等于给高铁换涂装，轨道没变。句式层级和段落层级的改动权重远高于词级。
3. **学术论文天生"像 AI"。** 规范、书面、结构严谨本身就是被检测的诱因，所以你会看到自己逐字写出来的段落也被标红。**这不是你写错了，是文体本身的假阳性。**

由此得到本指南的三条总原则：

- **结构先行**：先改语序、句式、段落节奏，再碰词；
- **具体优先**：把抽象拔高换成可核验的具体（数值、条件、机制、边界）；
- **语体守门**：任何改动后回头问一句"这还是论文吗"，不是就退回去。

## 1. 三级落点：只有中间那列合格

这是判断一次改写好不好用的**唯一标尺**。左边没改到位，右边改坏了。

| 场景 | ❌ 降重不足（仍像 AI） | ❌ 降重过度（口语化） | ✅ 恰当（书面学术） |
|---|---|---|---|
| 引言背景 | 近年来，随着信息技术的不断发展，该领域受到广泛关注 | 这几年这块儿火得不行，谁都在搞 | 2020 年以来，该方向年发文量增长约两倍，逐渐成为研究热点 |
| 结果陈述 | 实验结果充分表明该方法具有显著优越性 | 一测就知道这方法真的行 | 在三组测试集上，该方法的平均误差低于对照方法约 12% |
| 归因 | 上述差异归因于多种因素的综合作用 | 说白了就是好几个原因凑一块儿了 | 这一差异可能主要来自样本分布不均与特征冗余两个方面 |
| 难点描述 | 该问题的复杂性不容忽视 | 这事的难度比表面看着大多了 | 该问题涉及多变量耦合，难以用解析解直接求解 |
| 方法过程 | 通过一系列精心设计的步骤实现了研究目标 | 一点点磨出来的，中间踩了不少坑 | 预处理依次经过去噪、归一化与特征选择三步完成 |
| 局限 | 尽管取得一定成果，但仍存在局限性 | 当然啦，这方法也不是万能的 | 本文仅在实验室条件下验证，放大到真实场景后的表现尚待考察 |
| 推断 | 这无疑证明了假设的正确性 | 我们感觉这基本就对了 | 该结果支持原假设，但样本量有限，结论有待更多数据验证 |
| 展望 | 未来该领域必将迎来广阔的发展前景 | 以后这块儿肯定越来越牛 | 后续可将该方法扩展到多模态数据，检验其泛化能力 |
| 术语 | 交替使用"凝胶/胶体/水凝胶"指同一对象 | 同一概念换三种叫法 | 全文统一使用"凝胶" |

**口诀：更像人 ≠ 更口语。更像人 = 判断落回具体的数据、机制、条件。**

## 2. 三步流程

### 第一步：划保护区（先做，否则后面必出错）

动笔改之前，把下面这些片段圈出来，**全程原样保留、不参与改写**：

- 参考文献编号与条目、脚注；
- 图表编号、公式、变量符号；
- 数据、百分比、显著性水平（如 `P<0.05`）；
- 专业术语、定理、量表名称；
- 直接引语（引号内的原话）。

**保护区是硬约束**：改写不得为了"更像人"往里面补数值、补样本、补文献。原文没有的事实，一个字都不许加。

### 第二步：扫描定位高风险段落

逐段打勾，命中一项记 1 分，**≥4 分为高风险段**，优先处理：

- [ ] 段首是"依据/基于××理论""随着××的发展"
- [ ] 段末是"此案例印证了…""由此可见…""综上所述…"
- [ ] 出现整齐的"首先/其次/再次""其一/其二/其三"
- [ ] 出现"该设计基于…体现了…"这类被动分析套话
- [ ] 出现"面临的核心问题是""关键在于"
- [ ] 三个以上完全对称、等长的并列句
- [ ] AI 高频词密度过高（每段超过 2 个）
- [ ] 模糊归因（"专家认为""研究表明"无出处）
- [ ] 填充短语或过度限定（"值得注意的是""在一定程度上潜在地"）
- [ ] 结尾是"具有重要意义""前景广阔"
- [ ] 相邻多段结构高度雷同

### 第三步：按优先级重写

1. **移位**：理论名从段首挪到段中，让现象描述先行；
2. **砍尾**：删掉段末总结套句，用转折句或提问推进到下一段；
3. **破对称**：三元并列改成"一项展开、一项一笔带过"，或干脆只写两项；
4. **换词**：清 AI 高频词，优先处理最高优先级词表；
5. **去模糊**：模糊归因要么补出处，要么改成本文的判断；
6. **注视角**：加一句研究者的判断、疑惑或意外发现（见第 4 节）。

## 3. 模式清单与改法

### 3.1 内容层

**① 理论起笔**
> ✗ 依据社会建构主义理论，知识并非客观存在于外部世界，而是通过社会互动建构而成。
> ✓ 在课堂观察中，学生并非被动接收教师传递的知识，他们持续通过与同伴对话修正自己的理解。社会建构主义理论恰好能解释这一现象。

规律：把理论名从段首移到段中，现象先行。

**② "此案例印证了…"收尾**
> ✗ 此案例印证了目的论的核心观点。这提示我们，翻译决策需基于对目标读者的定位。
> ✓ 问题的关键不在于是否"忠实"于原文，而在于目标读者究竟需要什么。既然如此，意译是主动选择，而不是妥协。

**③ 编号式并列**
> ✗ 该方案基于三重考量：首先…；其次…；再次…。
> ✓ 这一方案背后有几层现实考量。最根本的是数据问题：现有语料库覆盖范围有限。此外，人工标注成本也是一道门槛。至于算法偏差，目前连系统性讨论都还不充分。

规律：各点篇幅与其重要性成正比，不要等长。

**④ 被动分析套话**
> ✗ 该方法的选择基于研究问题的复杂性，体现了定性与定量相结合的研究取向。
> ✓ 混合方法的选用，是在初期纯定量分析无法解释几个关键异常值之后，才决定引入深度访谈补充。

**⑤ 模板化问题陈述**
> ✗ 研究者面临的核心问题是，如何在保证效度的前提下实现跨文化样本的可比性。
> ✓ 一套在中国语境下设计的量表，直接搬到另一个国家的样本上用，量的还是同一个构念吗？跨文化比较的难点正在这里。

**⑥ 三元对称**
> ✗ 本研究具有三方面意义：理论上…；实践上…；方法上…。
> ✓ 本研究对现有理论框架有一定补充——至少在处理"非正式制度"这一变量时，既有模型的解释力存在明显局限。对政策实践而言，结论或许也有些参考价值，但推广时应当审慎。

**⑦ 画蛇添足的总结句**
"综上所述 / 由此可见 / 不难发现 / 可以看出" → 删除；需要衔接时改用过渡提问或转折。

**⑧ 模糊归因**（这条同时是学术规范问题，不是风格问题）
> ✗ 专家认为，社交媒体在政治动员中发挥着至关重要的作用。
> ✓ 根据 Boulianne（2015）对 38 项研究的元分析，社交媒体使用与政治参与意愿之间存在正相关。

无出处就必须改成本文自己的判断，禁止借"专家"造权威。**这也是 AIGC 检测最容易抓住的特征之一。**

**⑨ 填充短语与过度限定**
- 值得注意的是，数据显示… → 数据显示…
- 不难发现，两者之间存在… → 两者之间存在…
- 该政策可能在一定程度上潜在地对指标产生某种程度的影响 → 该政策可能影响相关指标，但现有数据尚不足以确认方向。

一个句子只留一个限定词。

**⑩ 泛化结论**
> ✗ 综上所述，本研究具有重要的理论意义和现实意义，为相关领域提供了新思路。
> ✓ 如果本文提出的"制度性摩擦"变量确实重要，那么在制度变迁较快的地区，相关指标的波动幅度应当更大，这是一个可用现有数据检验的命题。

### 3.2 语言层

**⑪ AI 高频词（每段 ≤2 个）**

| 最高优先级（几乎只见于 AI 文本） | 替换 |
|---|---|
| 值得注意的是 | 有意思的是 / 一个细节是 / 删除 |
| 至关重要 | 关键 / 必要 |
| 深入探讨 | 仔细考察 / 详细分析 |
| 系统性、全方位、多维度 | 全面 / 各方面 / 从不同角度看 |
| 显著提升、全面提升、稳步提升 | 明显增强 / 逐步提高 |
| 不可或缺、举足轻重 | 必需 / 重要 |
| 深远影响、广泛关注 | 长期影响 / 关注 |

| 高优先级 | 替换 |
|---|---|
| 此外 | 另一组数据则显示 / 从另一角度看 / 删除 |
| 与此同时 | 同时 / 另一方面 |
| 综上所述 | 把以上结论放在一起看 / 删除 |
| 研究表明、分析认为 | 实验表明 / 从结果来看 / 据此推断 |
| 旨在 | 为了 / 目的是 |
| 赋能、助力 | 支持 / 帮助 / 有利于 |
| 聚焦、锚定 | 关注 / 集中于 / 围绕 |
| 凸显、彰显、展现 | 突出 / 显示 / 表现 |
| 阐述、阐明 | 说明 / 解释清楚 |

> 替换时**不要全文统一替换成同一个词**——那会制造新的规律性。每处用不同说法。

**⑫ 系动词回避**
> ✗ 语言作为文化传承的重要载体，扮演着连接过去与现在的桥梁角色。
> ✓ 语言是文化传承的主要媒介，也是一个族群辨认自身的重要标记。

该用"是"就用"是"。

**⑬ 过度对仗**
> ✗ 该研究突破了传统范式，填补了理论空白，创新了分析视角，丰富了研究方法。
> ✓ 该研究最主要的贡献，在于提出了一个此前被忽视的分析维度。

**⑭ 破折号密度**
一段最多 1 个"——"。超了就换成逗号、句号或括号。破折号是强口癖，宁严勿宽。

### 3.3 风格层

**⑮ 加粗滥用**：正文全文 ≤5 处。

**⑯ 段落节奏**：连续 3 段以上长度相近时，把其中一段展开（补操作观察）或压缩（合并冗余）。但**不要为了节奏把句子拆成电报式碎句**——那不是"人味"，那是坏稿子。

**⑰ 悬崖式短句**：学术语体里可以偶尔用短句制造停顿，但每句仍须是完整的书面陈述句。

## 4. 注入"人的质感"——但只在允许的地方

去 AI 味只是减法，光做减法会得到"干净但均匀"的文本，一样像机器。要做加法，但加的是**书面学术**的东西：

**可以加（真实优先）：**
- **承认局限**："本文仅在实验室条件下验证，工业放大后的表现尚待考察。"
- **表达意外**（真有其事时才写）："出乎意料的是，访谈中没有一位受访者提到这一点。"
- **保留判断**："一种可能的解释是……；不过该解释无法说明……"
- **审慎推断**："这一结果可能源于样本分层不均，有待扩大样本验证。"

**绝对不加：**
- 编造的访谈、样本、异常值、文献 —— 这是学术不端，不是风格问题；
- "笔者觉得""说实话""说白了""这事儿""踩坑""手感"等口语表达；
- 网络用语与情绪词：绝绝子、破防、离谱、崩了、气死、笑死；
- 硬造的"金句"、反问、抒情。

**噪声预算**：每千字允许保留 2~3 处轻度模式化特征（例如一处两项并列、一个"值得注意的是"）。全部磨平会因过度均质反而更像机器稿。

## 5. 输出前的自检清单

| 检查项 | 标准 |
|---|---|
| 模糊归因 | 0 处无出处的"专家认为/研究表明" |
| 段末套句 | 全文 ≤1 处"此案例…了/由此可见" |
| 泛化结尾 | 结尾无"具有重要意义/前景广阔" |
| 理论起笔 | ≤20% 的段落以"依据××理论"开头 |
| AI 高频词 | 每段 ≤2 个 |
| 加粗 | 正文 ≤5 处 |
| 破折号 | 每段 ≤1 个 |
| 术语一致 | 同一概念全文一个叫法，无同义词轮换 |
| 节奏 | 段落内有长短句交错，句句完整 |
| 口语 / 网络词 | 0 处 |
| 事实完整性 | 未新增任何原文没有的数据、案例、文献 |
| 语体 | 通读一遍，仍然像论文 |

**任何一项不过，改回书面表达——语体优先于"降低率"。**

## 6. 评分（改写完成后自评）

| 维度 | 问自己 | 分 |
|---|---|---|
| 直接性 | 在陈述事实，还是在绕圈宣告？ | /10 |
| 节奏 | 句子长短有没有变化？ | /10 |
| 真实性 | 读起来像一位具体学者在说话吗？ | /10 |
| 信息密度 | 每句都承载信息，没有废话？ | /10 |
| 学术规范 | 归因具体、限定合理、语域一致？ | /10 |
| 抗模式化 | 规律性是否被充分打破？ | /10 |

- 54–60：可直接提交
- 42–53：针对扣分项局部修补
- <42：高风险段落重写

## 7. 常见错误

| 错误做法 | 为什么错 |
|---|---|
| 只换同义词 | 句式与结构才是主要特征，换词几乎无效 |
| 塞错别字、加"嗯/啊" | 检测器能识别刻意制造的错误，且毁语体 |
| 整篇改成口语 | 均质口语同样是强特征，还过不了人审 |
| 只改首尾 | 检测器扫全文，中间段落权重一样 |
| 全靠破折号/加粗制造"节奏" | 这两样本身就是 AI 特征 |
| 用"专家认为"替换具体引用 | 这是 AIGC 检测最容易命中的模糊归因，也是硬性学术问题 |
| 追求 0% | 人类论文不可能零痕迹；多数学校线在 15%~20%，底线以学校规定为准 |
| 让 AI 整篇重写一遍 | 实测会叠加 AI 指纹，有时不降反升 |

## 8. 改完还降不下来怎么办

按这个顺序排查，而不是加大口语化力度：

1. **是不是只做了词级替换？** 回到句式与段落层级。
2. **是不是段落结构太整齐？** 每段都是"总—分—总"就打破了。
3. **是不是论证本身空洞？** 空心论证无论如何润色都像机器写的 —— 回去补检索、补材料、补判断。
4. **是不是撞上了文体假阳性？** 规范学术文体本身就会被误判，这种情况应当保留原文并准备说明材料，而不是把论文改坏。

## 9. 合规与诚信边界

- 本指南只做**表达层**改写：不改研究设计、不改数据、不改结论、不改文献。
- 不提供、不推荐"降 AI 检测"商业化工具；不做绕过检测的对抗性处理。
- 学校/期刊要求披露 AI 使用情况时，如实披露；本插件的润色属于语言协助，不改变作者对内容的责任。
