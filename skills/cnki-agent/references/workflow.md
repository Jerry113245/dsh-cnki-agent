# CNKIAgent 工作流

## R3 检索：多关键词顺序检索

```
用户需求
  ↓ 拆解检索词单元（主题词 / 对象 / 方法 / 情境 / 时间）
  ↓ 判定模式 precise | general
cnki_search { keywords: [k1, k2, k3], mode, site, maxResultsPerKeyword, saveTo }
  ↓ 每个词单独执行，单条检索式写入报告
检索报告（含命中、失败、跑偏说明）
```

要点：
- 单条检索式必须可复现，日期与站点一起记录。
- 某个词零命中时不要改口说"没有研究"，要换词/换字段重跑并说明。
- 知网页面常需登录，网页抓取可能被墙或需验证码；此时改用 `web_search` + `web_fetch` 抓公开摘要，并在报告中标注"未取得全文"。

## R4 精读：编辑视角八步

1. 元信息 → 2. 结构与目录 → 3. 引言逐句解剖 → 4. 理论基础是否真用 → 5. 研究设计可复现性 → 6. 发现是否回应问题 → 7. 讨论是否回扣理论 → 8. 语体与 AIGC 特征。

每一步输出"观察 + 判据 + 可迁移做法"三列，不允许只给形容词评价。

## R2 写作链（分步，等确认）

1. **大纲**：三级标题，每节三行说明（解决什么问题 / 用什么材料 / 与前后关系）；标出最需论证的三处。
2. **引言**：500~800 字，4~6 段，段间转折承接；写完停下。
3. **正文**：逐节 800~1000 字，判断 → 材料 → 关系 → 衔接。
4. **校订**：去冗长、统一概念、补过渡；不改结论；可疑处另列。
5. **审计**：引用与条目双向校对，标注未核实项。
6. **排版**：docx 技能 + python-docx，样式先行，三线表，域生成目录页码。

## R5 修订与审计

修订给"优化后全文 + 修改类型汇总 + 待作者确认清单（逻辑/事实/引用）"；参考文献审计给"条目—正文位置—可核实性"三列表，未核实一律标红。
