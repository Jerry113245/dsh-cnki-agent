# 论文插图 · 架构图 / 流程图（DIAGRAM-PLAYBOOK）

> 解决一件事：**论文里的图为什么糊，以及怎么画成不糊的。**
>
> 一句话结论：**糊 = 位图被放大或重采样；不糊 = 从源头就是矢量。**
> 截图、JPEG、PNG 截图粘贴、Visio 直接 Ctrl+V——这四件事是论文插图 90% 的模糊来源。

---

## 0. 先认清"三重栅格化"

一张 Visio 图从画好到进 PDF，要过三道可能把它变成位图的关：

| 阶段 | 发生了什么 | 后果 |
|---|---|---|
| ① 粘贴 | `Ctrl+V` 默认走 OLE 嵌入，Word 用 GDI+ 按约 **96 dpi** 抓一张位图快照 | 一放大约 120% 就看到锯齿 |
| ② 存储 | Word 默认压缩文档内图片（Office 2016+ 才有"高保真"选项） | 颜色断层、细线断裂 |
| ③ 导出 PDF | Word 内建 PDF 引擎对已栅格化的图按目标 DPI（常见 220 dpi）**再采样一次** | 出现摩尔纹、文字发虚 |

**诊断矩阵**（30 秒判断你的图到底是矢量还是位图）

| 检测 | 矢量正常表现 | 位图异常信号 |
|---|---|---|
| Word 里右键图片 | 有【编辑图片】或【Visio 对象 → 编辑】 | 只有【设置图片格式】，或报"找不到应用程序" |
| 放大到 400%（Ctrl+滚轮） | 边缘始终锐利 | 明显马赛克/锯齿 |
| 另存 PDF 后用 Acrobat 看图像属性 | `Vector graphic` / 无图像对象 | `Image (RGB, 96 dpi)` |
| 文件体积 | 小（几 KB） | 大（几百 KB 起步） |

## 0.1 必做的两个全局设置（一次设好，永久生效）

1. **文件 → 选项 → 高级 → 图像大小和质量**
   - 勾选【不压缩文件中的图像】
   - 【默认分辨率】改为 **高保真**
   - 顺手勾选【放弃编辑数据】（减小体积；但如果你还要在 Word 里微调图，就别勾）
2. **打印质量**：文件 → 选项 → 高级 → 打印 → 取消"使用草稿品质"

> 注意：这两项是**文档级设置**，新文档会回落到默认。做论文时先在新文档里设一次，或从模板文档另存。

## 1. 五条画图路线，按"能不能用"排序

| 路线 | 产物 | 是否矢量 | 能否在 Word 里改 | 需要什么 | 推荐度 |
|---|---|---|---|---|---|
| **A 代码生成原生形状** | docx 内的 DrawingML 形状组 | ✅ 真矢量 | ✅ 双击即可改字改色 | 只要 Python | ★★★★★ |
| **B Word / WPS 原生绘图** | 直接画在 Word 里 | ✅ 真矢量 | ✅ 原生 | 只要 Office | ★★★★☆ |
| **C draw.io → SVG** | .svg | ✅ | ❌ 只能整体缩放 | 浏览器 | ★★★★☆ |
| **D Visio → 选择性粘贴 EMF** | 增强型图元文件 | ✅ | ✅（双击回 Visio） | 装了 Visio | ★★★★★（有 Visio 时） |
| **E 位图另存 300/600 dpi** | .png / .tif | ❌ | ❌ | — | ★★☆☆☆（仅当期刊强制） |

**本机现实**：这台机器装的是 **WPS Office**（Word 兼容引擎，COM 里显示 Version 14.0 / Build 12.1.0.28022，Path 指向 `D:\WPSOFF~1\1210~1.280\office6`），**没有安装 Microsoft Word，也没有安装 Visio**（`Visio.Application` 的 CLSID 未注册）。

所以：
- **路线 D（Visio）在本机走不通**，只能作为"你换到有 Visio 的机器时"的参考；
- **路线 A 是本机首选**——不依赖任何 Office 组件，生成出来的是 Word/WPS 都能打开的原生矢量形状；
- 路线 B 也完全可行（WPS 的"插入→形状"和 Word 基本一致）。

## 2. 路线 A：代码生成原生矢量形状（本插件已内置）

```bash
python assets/tools/draw_diagram.py build spec.json 图3-2.docx --caption "图 3-2 平台总体架构"
python assets/tools/draw_diagram.py build spec.json 图3-2.svg      # 给 draw.io / AI 二次编辑
python assets/tools/draw_diagram.py build spec.json 图3-2.png --dpi 600   # 期刊只收位图时
```

规格文件只要写"谁连谁"，布局自动排：

```json
{
  "title": "图 3-2 平台总体架构",
  "nodes": [
    {"id": "c1", "label": "Web 前端", "shape": "round", "level": 0},
    {"id": "g",  "label": "统一接入网关", "level": 1},
    {"id": "s1", "label": "用户服务", "level": 2},
    {"id": "db", "label": "业务库", "shape": "cylinder", "level": 3}
  ],
  "edges": [
    {"from": "c1", "to": "g"},
    {"from": "g", "to": "s1", "label": "路由"},
    {"from": "s1", "to": "db", "dashed": true}
  ]
}
```

- `shape`：`rect` 矩形 / `round` 圆角 / `terminator` 起止 / `diamond` 判断 / `ellipse` 圆 / `parallelogram` 数据 / `cylinder` 存储 / `hexagon` 准备
- 不写 `level` 就按最长路径自动分层；写了 `level` 就按你指定的层排（手工微调用）
- 跨度 ≠ 1 的边（跳层、回边）自动走右侧通道，不会穿过中间节点
- 输出 docx 里是**一个形状组**：整组可拖动缩放，组内每个框可单独改字、改填充色、改线宽——这就是"原生矢量"的价值

> 已验证：生成的 docx 经 WPS 转 PDF，PDF 内图形全部为路径对象，放大不失真；图中文字为真实文本（可搜索、可编辑）。

## 3. 路线 B：Word / WPS 手绘

**基本流程**：插入 → 形状（先选形状再拖，或选中后按住 Shift 画正方形/正圆）→ 画完右键【添加文字】。

**必须会的四件事**

| 需求 | 操作 |
|---|---|
| 多个框一样大 | 选第一个画好，`Ctrl+D` 复制，或画完选中多个 → 形状格式 → 大小里统一填数值 |
| 对齐、等间距 | 多选（Ctrl+点）→ 形状格式 → 对齐 ▾ →【左对齐】+【纵向分布】 |
| 让箭头跟着框走 | 用**连接符**（插入 → 形状 → 线条里的带箭头连接符），端点吸附到框上的灰点；移动框时箭头自动跟随 |
| 整组一起动 | 全选 → 右键【组合】；或 `Ctrl+G` |

**避坑**

- ❌ 用"空格 + 回车"顶位置——字号一改全乱
- ❌ 把图拖到"绘图画布"外面——跨页会错位；要么用画布，要么全选组合后用"嵌入型"环绕
- ❌ 用 SmartArt 画技术架构图——SmartArt 的布局逻辑会自动重排，你要的"分层 + 跨层箭头"它不听你的；SmartArt 只适合纯层级/循环关系的示意
- ✅ 图的环绕方式设成**嵌入型**（随文字走，不会因为改段落跑位），或"上下型"（可单独占一块）

## 4. 路线 C：draw.io（diagrams.net）→ SVG

**三个必改设置**（否则导出 SVG 进 Word 会：文字被截断 + 底部多一行英文小字）

1. `Ctrl+A` 全选 → 右侧取消勾选 **Formatted Text**（格式化文本）→ 部分字体字号会变，手动调整
2. 空白处右键 → 取消勾选 **Word Wrap**（自动换行）
3. 调整到满意后：文件 → 导出为 → **SVG** → 关闭"文本作为图片"之类的选项，保持文字为 `text` 元素

**Word 里插入 SVG**：插入 → 图片 → 选 .svg（Word 2016+/WPS 新版支持）。
注意：SVG 在 Word 里可以**右键 → 转换为形状**，转完就能像原生形状一样改字改色。

**坑**：早期版本 Word 打开 SVG 会显示不全（裁剪）。若遇到，改用 EMF 或用路线 A/B。

## 5. 路线 D：Visio → Word（有 Visio 时最优）

**方法一：选择性粘贴为 EMF（最推荐）**

1. Visio 里 `Ctrl+A` → `Ctrl+C`
2. Word 里【开始】→ 粘贴 ▾ →【选择性粘贴】（或 `Ctrl+Alt+V`）
3. 选**【图片（增强型图元文件）】**→ 确定
4. 验证：`Ctrl+滚轮` 放大到 400%，边缘应始终锐利

**方法二：插入对象（保留可编辑性）**

插入 → 对象 →【由文件创建】→ 浏览到 .vsdx → 勾选【链接到文件】（可选）→ 确定。
双击图片可回 Visio 编辑。缺点：换机器打开可能提示"无法加载嵌入的 Visio 对象"。

**方法三：导出高分辨率位图（期刊强制位图时）**

文件 → 导出 → 更改文件类型 → PNG / TIFF → 保存 → 在【输出选项】把**分辨率**从"屏幕"改成【打印机 300×300 像素/英寸】，要求更高就选【自定义】填 600；【大小】选【打印机】或【源】。

**两条救命技巧**
- 字体转曲：`Ctrl+Shift+Q`（把文字转成曲线），彻底避免对方机器缺字体导致换字
- 导出 EMF 前把页面尺寸设成图的实际外框（设计 → 大小 → 适应绘图），否则 EMF 里会有大片空白

## 6. SVG / EMF / PNG 怎么选

| 格式 | 本质 | 适合 | 不适合 |
|---|---|---|---|
| **EMF** | Windows 原生矢量 | Word/PPT 内嵌，兼容性最好，可回编辑 | 跨到 macOS / LaTeX |
| **SVG** | Web 矢量 | Word 2016+、draw.io 二次编辑、LaTeX | 老版本 Office、部分投稿系统 |
| **PNG/TIFF 600 dpi** | 位图 | 期刊投稿系统只收位图 | 需要后期放大的场合 |
| **PDF** | 矢量容器 | LaTeX、投稿系统 | Word 里当图片用 |

**论文场景的判断**：Word 稿 → **EMF 或原生形状**；需要被别人二次修改 → **SVG**；投稿系统卡格式 → **600 dpi PNG**。

## 7. 论文插图的排版规范（比"清晰"更容易丢分的地方）

| 项 | 通行做法 | 说明 |
|---|---|---|
| 图题位置 | 图**下方**居中 | 表题在表**上方**，两者不可颠倒 |
| 图题格式 | "图 3-2 平台总体架构" | 章号-序号 + 空格 + 图名；用题注域自动编号 |
| 图中字号 | 比正文小 1–2 号（正文小四 → 图中五号或小五） | 图中文字**不得大于**正文，否则视觉喧宾夺主 |
| 线宽 | 0.5–1 pt；框图边框 1–1.5 pt | 低于 0.25 pt 印刷会断线 |
| 留白 | 图与正文上下各空 6–12 pt | 不要用回车堆空白，用段前段后 |
| 宽度 | 单栏图不超过版心宽度，通栏图不超过 100% | 超出会被 Word 压回去，比例失真 |
| 黑白可读 | 仅靠颜色区分的元素，必须再用**线型/填充纹理/标注**区分 | 黑白打印或色弱读者 |
| 图内英文 | 与正文西文同字体（Times New Roman） | 中英混排别用两种无衬线体 |
| 首次引用 | 正文必须先出现"如图 3-2 所示"，再出现该图 | 不能先出图后引 |

## 8. 交付前验收（5 条，30 秒做完）

1. **放大检验**：Word 里 `Ctrl+滚轮` 到 400%，所有线条和文字边缘锐利
2. **PDF 检验**：另存 PDF，用 Acrobat/福昕看图像属性——应是 `Vector graphic`，不该有 96 dpi 的 Image 对象
3. **体积检验**：一张架构图正常几 KB 到几十 KB；几百 KB 基本是位图
4. **右键检验**：右键图能"编辑图片/转换为形状/编辑对象"——说明是矢量的
5. **黑白检验**：临时把文档转灰度打印预览，信息仍能读懂

> 如果 1–4 有任何一条不过，就不要指望"调高 PPI"能救——**PPI 只能放大已有像素，不能恢复矢量精度**。

## 9. 常见误区速查

| 误区 | 事实 |
|---|---|
| "截图后用 PS 放大 2 倍就清楚了" | 插值放大只会更糊，不会增加信息 |
| "另存 300 dpi 的 JPEG 就够清晰" | JPEG 有损压缩，细线和文字最先崩；要位图就用 PNG/TIFF |
| "Word 里图变小了再拖大没关系" | 位图拖大 = 放大像素；矢量拖大 = 重算，这才是矢量的意义 |
| "Visio 的 Ctrl+V 是最快的" | 它是最容易糊的一条路，多按一次 `Ctrl+Alt+V` 就解决 |
| "图越花越显得工作量足" | 审稿人看的是信息密度和逻辑，不是装饰；一张图只讲一件事 |
| "调高 Word 的默认分辨率就等于矢量" | 那是位图的上限设置，跟矢量无关 |

- Microsoft 支持：《更改在 Office 中插入图片的默认分辨率》——Office 2016 起提供"高保真"，PowerPoint 2016+ 默认即高保真，Word/Excel 需手动设。

- CSDN《公式不变形指南：Word/MathType 插入 Visio 的 EMF 与 OLE》——OLE 与 EMF 的坐标/DPI 差异。
- elssky《draw.io SVG 矢量图导入 Word 高清无损方案》——Formatted Text 与 Word Wrap 两处必改设置及底部水印来源。
